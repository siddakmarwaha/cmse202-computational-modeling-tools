# CMSE 202 — Computational Modeling Tools & Techniques

![Python](https://img.shields.io/badge/python-3.9%2B-blue) ![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange) ![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

Second course in MSU's computational modeling sequence: object-oriented programming, version control, agent-based modeling, network analysis and introductory machine learning.

**Course:** CMSE 202 — Computational Modeling Tools and Techniques  
**Term:** Fall 2022  
**Institution:** Michigan State University

## Highlights

- **Project:** classifying stars vs. galaxies from SDSS photometry with a from-scratch perceptron, compared against scikit-learn's Perceptron and MLPClassifier.

## Getting Started

```bash
git clone https://github.com/siddakmarwaha/cmse202-computational-modeling-tools.git
cd cmse202-computational-modeling-tools
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```
